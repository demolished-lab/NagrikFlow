# Compliance & Organizational Pack

Templates for the non-code track of government readiness: data-protection
accountability, incident response, DPDP Act 2023 mapping, security testing,
and usability validation. These are **drafts for owner review and execution** —
legal counsel should review before external use.

| Doc | Purpose | Status |
|---|---|---|
| [DPO_APPOINTMENT.md](DPO_APPOINTMENT.md) | Data Protection Officer appointment letter (DPDP s.10) | Template — needs signatory + name |
| [BREACH_RESPONSE.md](BREACH_RESPONSE.md) | Personal-data breach procedure + CERT-In 6h reporting path | Adopt by owner |
| [DPDP_COMPLIANCE_MAP.md](DPDP_COMPLIANCE_MAP.md) | Clause → where the codebase/ops satisfies it, with gaps | Maintained with the code |
| [PEN_TEST_SCOPE.md](PEN_TEST_SCOPE.md) | Scope + rules of engagement for an external penetration test | Ready to issue |
| [USABILITY_TESTING_PROTOCOL.md](USABILITY_TESTING_PROTOCOL.md) | 8-participant moderated usability study protocol | Ready to schedule |

Relationship to code: `PRODUCTION_READINESS_REPORT.md` tracks automated
readiness (tests, gates, secrets, probes); this pack tracks the human and
organizational controls that no test suite can prove.
